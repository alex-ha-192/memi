Code signing policy

Last updated 20 November 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installer (YourMemi-<version>.msi) and the program inside it are signed for each tagged release. They're built from the public source code by GitHub Actions, on GitHub's own machines, and sent to SignPath straight from that build. Nothing built on a personal computer is signed.

Until the signing certificate is in place, Windows releases are unsigned, and Windows may warn about them.

Team roles

  • Committers and reviewers: alex-ha-192. Changes from anyone else are reviewed before they're merged.
  • Approvers: alex-ha-192. Every release is approved by hand before it's signed.

Privacy

The program doesn't send information to any other networked system unless you ask it to, by turning on sync with your own Google account. Details are in the privacy policy.

Uninstalling

Open Windows Settings › Apps › Installed apps, find Your Memi, and choose Uninstall. Your notes are kept in %APPDATA%\YourMemi; delete that folder too if you want them gone.
